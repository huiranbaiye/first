# 猜数字小游戏（Guess Number Game）

计算机协会通识任务 2 · first 项目

---

## 一、项目简介

这是一个用 Python 写的命令行小游戏。电脑会随机想好一个 **1 ~ 100** 之间的整数，玩家在命令行里输入自己猜的数字，电脑会根据猜测结果提示 **"大了"** 或 **"小了"**，直到玩家猜中为止，并统计一共猜了几次。

## 二、游戏规则

1. 程序启动后，电脑随机生成一个 1~100 的整数（玩家看不到）。
2. 玩家在命令行输入一个整数并回车。
3. 电脑给出反馈：
   - 猜的数 **大于** 答案 → 提示"大了！往小了猜～"
   - 猜的数 **小于** 答案 → 提示"小了！往大了猜～"
   - 猜的数 **等于** 答案 → 恭喜猜中，游戏结束。
4. 游戏结束时，显示玩家**一共猜了多少次**。

## 四、运行环境

- 操作系统：Windows
- Python 3.x（已安装并配置好 PATH，能直接在命令行用 `python` 命令）

## 五、运行方法（按任务要求，用命令行运行）

1. 按 `Win + R`，输入 `cmd`，回车，打开命令提示符。
2. 用 `cd` 命令进入项目文件夹：
   ```
   D:
   cd D:\play_do\first
   ```
3. 运行 Python 程序：
   ```
   python guess_number.py
   ```
4. 按照屏幕提示输入数字即可开始游戏。

## 六、程序逻辑（看懂代码用）

整个程序的核心思路只有四步：

| 步骤 | 代码关键字 | 作用 |
|------|------------|------|
| ① 准备答案 | `random.randint(1, 100)` | 电脑偷偷生成 1~100 的随机数 |
| ② 循环接收输入 | `while True:` + `input()` | 反复让玩家猜，直到猜中 |
| ③ 比较并提示 | `if / elif / else` | 大了、小了、猜中三种情况分别处理 |
| ④ 跳出并报次数 | `break` + 计数器 `count` | 猜中后结束循环，显示猜了几次 |

**用到的 Python 知识点：**
- `import random`：导入标准库生成随机数
- 变量赋值、整数转换 `int()`
- `while` 死循环与 `break` 跳出
- `if / elif / else` 多分支判断
- f-string 格式化输出（`f"..."`）
